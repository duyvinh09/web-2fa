# Công Cụ Tiện Ích Chuyển Đổi Mã Xác Thực 2 Yếu Tố

Công cụ này hỗ trợ chuyển đổi mã xác thực hai yếu tố (2FA) từ dạng chữ sang dạng số một cách nhanh chóng và tiện lợi. Giao diện hiện đại, đơn giản nhưng bắt mắt, được xây dựng với Tailwind CSS.

## Tính Năng
- Chuyển đổi mã 2FA từ dạng chữ sang dạng số.
- Nút "Enable OTP" để bắt đầu quá trình chuyển đổi.
- Nút sao chép mã nhanh chóng.
- Nút đặt lại để tạo mã 2FA mới.
- Giao diện thân thiện, hiện đại và dễ sử dụng.

## Cách Sử Dụng
1. Clone dự án từ [GitHub Repository](https://github.com/duyvinh09/web-2fa.git) bằng lệnh sau:

    ```bash
    git clone https://github.com/duyvinh09/web-2fa.git
    ```
2. Tham khảo API qua thư mục `api`.
3. Nhập mã 2FA dạng chữ.
4. Nhấn nút "Enable OTP" để bắt đầu chuyển đổi sang mã số.
5. Sử dụng nút "Copy" để sao chép mã số hoặc nút "Reset" để tạo mã mới.
6. Sử dụng mã xác thực để đăng nhập an toàn.
